# Sobind Yadav — Portfolio Website

Responsive personal portfolio using HTML, CSS, and vanilla JavaScript.

## Run
Extract the ZIP and open `index.html` in a browser. Recommended: VS Code + Live Server.

## Included
- Home/Hero with profile photo
- About, skills, project cards, contact, footer
- Responsive layout and mobile navigation

Update email, social links, and sample project information in `index.html` before presenting.
